eMaktab kirish sinovi (lokal)

1. Node.js o'rnatilgan bo'lsin (node -v).
2. Shu papkada: npm install --no-save tsx
3. Ishga tushirish: npx tsx server.mts
4. Brauzerda oching: http://127.0.0.1:3001
5. Login va parolni kiriting, "Kirish sinovi" ni bosing.

Eslatma: parol hech qayerga saqlanmaydi. Natija ko'rsatiladi (ism, rol yoki xato matni).
Bu vosita brauzeringiz turgan kompyuterdan so'rov yuboradi, shuning uchun eMaktab
serverida boshqa tasdiqlash so'ralmasligi kerak.
